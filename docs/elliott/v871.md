# V8.7.1：大小波段比較、歷史五段與白話解釋

本次保留原始日K、ABC/N、六套策略、正式分數、排行、原三價位、停損與 Kronos。新增計算只供研究與說明，沒有把數浪變成進場條件，也沒有放寬五浪硬規則。

## 實際計算變更

`elliott-wave-v1.js` 沿用 `structure-context-v1.js` 的同一個轉折點函式，分別用左右各 3、5、8 根完成日K觀察小、中、大波段。較大的波段必須真的等到較多根右側日K出現後才確認。三種尺度共用既有數浪引擎與硬規則，沒有混接不同尺度的轉折點。

原來的小波段有合格候選時維持優先；小波段沒有合格候選，才使用下一種合格尺度。大小波段有不同解讀時保留另一種結果，明確提醒分歧。這些窗口是研究參數，沒有宣稱是最佳參數。

新增 `scaleComparisons`、`selectedScale`、`scaleAlternative`、`scaleDisagreement`、`historicalCounts`、`diagnostics`。每項失效證據保留日期、實際高／低價、比較關卡、試算方向及尺度。第2與第4浪同時檢查段落內每一根日K，避免只看轉折端點而漏掉中途越界。

歷史五段以每個轉折的真正確認日期逐日重播，再使用當時的 ATR、趨勢與可得轉折驗證。後來的高點不能抹去先前記錄，也不會用現在的 ATR 回頭核准過去數浪。僅保留本次已核驗歷史窗口中最近三組不重複的合格形狀；不是永久完整歷史資料庫。`turnsConfirmed` 表示轉折資料完成確認，`interpretationConfirmed:false` 表示不能證明這就是唯一正確的艾略特數法。

修正原本轉折參數未實際帶進來源轉折函式的問題。參數和圖上 confirmedAt 現在一致；注入與來源不一致的轉折仍會被拒絕。

## 文字與圖片

`elliott-wave-visual-v1.js` 的同一份白話說明供網頁、個股研究圖、精簡圖、專業圖和大盤圖使用。有效的目前候選保持藍色；修正 ABC 保持橘色；只有歷史形狀可用時畫灰藍色「歷史1～5」，不標成目前位置。無合格數法時仍不畫五浪，改為解釋哪個日期、哪個價位讓試算不成立。

個股專業圖增加完整說明區，保留原報告所有區塊，不覆蓋原技術小圖；與原有大盤圖都使用 40px 白話說明。需要時增加單張 PNG 高度，不縮字、不裁切、不拆頁，寬度保持 1284，安全高度上限 8192。波浪關閉時仍保持原模板。浮水印、下載與原生分享介面保留。

`research-v83/market.js` 的網頁圖也使用相同歷史／目前分類。`version-v50.js`、兩個入口、圖片產生器、快取與相關版本斷言更新為 V8.7.1。
