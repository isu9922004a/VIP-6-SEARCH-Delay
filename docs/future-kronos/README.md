# V8.7.2：個股與大盤未來K棒走勢預測

新增獨立20個正式交易日圖片，一般版與浮水印版均為1284×2778。原本的波浪圖片、單日模型、四策略買進資格、排序、分數及停損完全保留。

## 使用者說明

- 藍線：150條模型收盤走法，每天各自取中間位置，不是保證路線。
- 深色帶：當天結果的中間一半；淺色帶：中間八成。這些占比不是實際勝率。
- 框線K棒：選取一條完整、OHLC全部有效的原始模型路徑。沒有合格完整路徑時保留真實收盤線與區間，不修價補K。
- 第20日三格數字只說明當天收盤分布；不是建議買價、停損或保證目標。
- 個股、大盤分別說明「還沒買」「已持有」。不把大盤模擬直接當成個股買進通知。
- 每張圖標明盤後基準日、未來交易日期、模型取樣數、價格基準限制。

## 真實推論及資料核對

固定原有NeoQuasar/Kronos-small、Tokenizer權重與上游程式版本；一次預測20個交易日，150次獨立取樣，不把單日結果延長成20日。CPU因果KV快取保留原本正規化、取樣器與溫度。實際150條20日試跑與原始未快取結果逐值相同；20步教師強制logit比較、跨批次重設及例外還原另有測試。

模型輸入需63～160根核驗日K，不跨越不明價格斷點補值。實際交易日曆、股票代號、市場、行情日、歷史指紋、固定權重與執行收據皆須一致。前端另核對公開檔案SHA256；切換股票或模型過期後不能繼續下載舊查詢結果。

公開檔案保留150條完整收盤路徑及一條合格完整OHLC路徑，以控制手機下載量。所有原始OHLC取樣壓縮後保留於Actions結果附件14天；發佈前與公開資料逐值比對，不把取樣失敗改成有效模型。

`.github/workflows/kronos-future.yml` 每日盤後排程並重試。同日完整結果通過指紋及檔案核對後略過重算；行情或輸入改變則重新計算。全市場分16片；每檔都須返回結果或具體原因，分片缺漏、重複、來源變動均阻止發佈。價格或歷史不足的股票仍使用原有核驗行情報告，不能承諾每檔每天都一定可預測。

## 每日部署容量

網站打包時只保留研究manifest與目前模型仍參照的日期目錄；原始程式庫的歷史檔案及官方逐日檔不刪除。`prepare-pages-runtime-data.cjs`會先核對每個現用來源存在，才清理暫存部署包，並檢查950MB容量預算。首次檢查將約1.019GB部署資料降至約0.3GB，避免每日歷史累積阻止新模型上線。
