# 全個股波浪圖片：新手白話第二版

沿用使用者核准的單張1284×2778版面。全部個股共用同一模板，文字與價位按目前已核對行情、波浪結果及既有開盤計畫切換，沒有寫死大聯大、價位或多空結論。

## 每張圖提供什麼

1. 目前偏多、偏空、回落、反彈、震盪或資料限制。
2. 真實日K、均線、成交量、波浪轉折標記及價格數字。
3. 波浪數字、虛線與紅綠K的白話解讀；歷史數浪與目前位置分開。
4. 還沒買：只有原開盤計畫為CONDITIONAL且買價、防守、上方空間有效時，才列有條件可評估範圍。WAIT、NO_TRADE及DATA不升級為進場。
5. 已持有：原停損優先、原失效參考或已完成日K低點的風險觀察。新買損失試算不得當成個人持股停損；未提供持股成本時不代填認賠價。
6. 原突破、回檔及結構失效參考價保留原值；未成立就說明條件還沒齊。

官方行情已核對但有短歷史或交易規則限制時，會明講「行情已核對，完整判讀仍有資料限制」，不把它誤寫成所有報價未核對。真正資料衝突仍保留阻擋，不補K、不猜價、不強行數浪。

## 檔案與分工

- `elliott-wave-stock-beginner-v1.js`：新增個股專用的純顯示模型與版面；獨立是為了保留大盤原版面，不是新增分析核心。
- `elliott-wave-report-v1.js`：接入同股票、日期、收盤及日線相符的既有openingPlan；缺少目前研究時才重用原四模型計算。計畫狀態改變即更新圖片身分，避免分享舊內容。
- `elliott-wave-visual-v1.js`：個股可選白話圖例，K線與波浪座標仍使用原計算；其他報告預設不變。
- `index.html`、`market-outlook.html`、`version-v50.js`：載入順序與快取版本更新；顯示版本維持V8.7.1。
- `scripts/tests/stock-wave-beginner.test.cjs`：多空、CONDITIONAL/WAIT/NO_TRADE/DATA、錯股/錯日期/錯價格、原價位及分享身分回歸。
- `scripts/tests/elliott-browser.cjs`：實際開啟與下載新個股模板，驗證浮水印、固定尺寸與原計畫數字一致。
- `scripts/audit-all-stock-images.cjs`：全部上市櫃逐檔產生波浪及原精簡PNG，增加模板、版面、身分、個人停損留空及進場狀態不升級檢查，保存JSON/CSV與圖片。
- `scripts/verify-deployed-frontend.py`：新增模板檔的發布位元組核對。

既有策略資格、排名、Kronos推論、停損計算、原專業及精簡報告不改。無新增行情API、無個人部位設定、無Cloudflare Worker變更或部署。本次僅GitHub Pages更新。

最終通過項目與逐檔數量以PR、Actions的ALL_STOCK_IMAGES_AUDIT及正式站驗收為準；資料不足及未證實績效的研究限制維持。回滾可revert合併提交，重新執行前端驗證與發布。
