# V8.7.1 波浪圖片白話版

個股及兩個大盤入口的獨立「波浪分析圖片」採用同一個白話資料模型與1284×2778單張版面。

- 分開顯示「現在走勢偏強／偏弱／震盪」及「可能第幾浪」，避免把無法數浪誤解成無法觀察趨勢。
- 走勢說明直接取自既有波浪結果的MA20、斜率及收盤；未通過資料驗證時不判斷。
- 仍沿用原本轉折及數浪規則。只畫行情中已有的轉折；沒有4、5浪就不預畫。
- 過去已完成的五段與目前位置分開，大小波段不同意時明確提醒。
- 原本三個價位保留；白話下一步僅從這些價位尋找收盤上、下方的觀察點，不改寫停損。
- 不再把舊日期的失敗數浪例子放在主要說明。詳細診斷仍保留在既有分析結果。
- 使用較大的真實技術圖、較短的說明卡，保留浮水印、PNG下載、原分享流程和行情變更攔截。

正式版仍是V8.7.1，資產快取標識改為V8.7.1-WAVEPLAIN1，報告結構版本為WAVE_REPORT_PLAIN_2。

## 驗證

執行npm ci、npm test（700項）、npm run test:contract（50項）、npm run research:validate。
波浪瀏覽器檢查16項、一般研究介面29項，以及大盤原報告手機版回歸通過。檢查390、428、768、1440寬度、正確的日期價格座標、下載、浮水印及原生圖片分享呼叫。

另外用2026/11/06大盤、2026/11/06三福化、2026/11/03台泥歷史快照驗證白話內容與圖上標記一致。台泥只出現1、2、3，不畫尚未形成的4、5。這些案例不能證明預測績效。

研究績效驗證仍因缺少逐日歷史母體與排名等資料而受阻。此更新不修改模型、正式分數、策略資格或資料契約，波浪仍是研究輔助。

瀏覽器測試使用Chromium手機視窗；原生分享使用測試替身檢查單一PNG傳遞，未操作實體iPhone或實際LINE收件。

## 發布與回滾

僅更新GitHub Pages前端；不需要部署Cloudflare Worker。合併後由既有流程先驗證、再發布、再檢查線上檔案與瀏覽器行為。若需回滾，反向提交本次合併的前端變更，保留行情資料，待同一發布流程通過後重新發布。
