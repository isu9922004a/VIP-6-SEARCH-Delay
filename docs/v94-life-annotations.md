# V9.4 生命線價牌與白話閱讀優化

此更新只調整呈現。V9.3.2 生命線核心、選股規則、排名、正式行情與 Kronos 模型資料均保留原檔。

- 圖 A 使用從 K3 前兩根到最新完成交易日的連續真實行情，顯示形成過程、首次收盤穿越及最新收盤，不拼接不同時段。
- 生命線使用 5px 虛線與直接相連的價牌。歷史參考為藍灰、目前支撐為薄荷青、目前壓力為金黃；每個價牌同時附文字角色，不能只憑顏色判讀。
- 最新收盤使用白色價牌；生命線與收盤接近、相等時，價牌分開排列，連接線仍指向原始價格座標。
- K3 取價位置使用菱形；首次收盤突破／跌破使用方向三角與日期、當天真實收盤價。價牌不覆蓋 K 棒；鄰近右軸刻度讓位，左軸完整保留。
- 圖 B 保留獨立座標。歷史參考不加入近期圖，仍有效但超出近期價格範圍的關卡以文字明示，不壓縮近期 K 棒。生命線畫在均線上方，保持可辨認。
- `fields().overview` 提供共用白話說明及 K3／K0／首次穿越證據；保留完整技術原文，所有既有報告 API 繼續支援。
- 高低點標示實際觀察根數；短線風險改用「最近漲得較快」「離最近5天平均價較遠」等白話，完整計算理由仍留在技術頁。

8099 圖片對照：最新完成日 2026-11-13 收盤 182.00；生命線取 2026-10-16 K3 最高價 70.90；2026-10-21 K0 收盤 70.40 屬成立當日價格；首次突破 2026-10-22，當天收盤 77.40。K0 收盤價與生命線取價不可混用。上述價格只用於驗收，正式模板沒有硬編碼股票或價位。

驗收涵蓋正式清單全部個股，不僅特定案例：獨立行情／收盤路徑核對、1284×2778 PNG 真正編碼、字形邊界、文字及日期遮蔽、價牌避碰、原始價位座標、K3 來源、首次穿越收盤價，以及實際像素顏色／生命線可見程度。`V9.4 independent life-line pages` 的四組 `every-stock` 工作全部執行並提供逐頁 SHA256 與代表性 PNG。

前端維持 V9.4，快取更新為 V9.4-LIFE94-2；核心及歷史事件版本不改寫。手機驗收為 Chromium iPhone 12 Pro Max 模擬，非 iPhone 真機或 LINE App 收送。
