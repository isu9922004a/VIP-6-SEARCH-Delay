# V8.2.2-R16：結構判讀、四模型論述與證據圖

本版把上傳教材中的「型態＋位置＋後續確認＋失效條件」轉成可重現的研究附層。正式六套選股的資格、分數、排序與排除名單不改；研究情境與研究榜狀態可能因修正誤判而改變。沒有修改或部署 Cloudflare Worker。

## 修復與新增

- 修正「前日碰均線、未通過守穩」被直接歸為支撐失敗：只有先前已建立、具事件日期的收復情境，後續完成收盤失守才列失效。
- 盤中越過壓力後收回保留風險警示，不再把尚未成立的突破當成整體結構已失效。
- 突破與回測使用事件日的固定關卡；失效帶保留事件時容差，不隨後來ATR移動。原始研究快照不可覆寫。
- 量比使用當日量／前5或20根完成日K均量，分母排除當日；前日縮量另比較更前5根，避免混用。來源、單位或跨來源量差衝突時，不能給可進場綠燈。
- 突破、回檔、回測、箱型及反轉分開輸出觸發、確認、失效、風險與進場狀態。量比1.2為現有突破研究參數，不是所有策略通用的有效門檻。
- 報酬風險先用最近已知上方關卡，不跳到較遠目標；沒有合理防守或關卡時，不產生停損／目標組合。候選參考不稱已確認支撐。
- 增加已確認轉折點的W底／三角研究、K線位置與下一根確認、RSI14波峰背離及開盤缺口／全區間缺口區分。這些是研究定義，沒有升格為正式選股條件或宣稱績效。
- D模型明確區分技術子集與外部資金／營收驗證；B9、C6等未知公式仍未知。不由OHLCV推定主力成本、洗盤、出貨、封單撤單或15%換手規則。

## 前端與報告

- 統一前端、摘要圖片、完整文字、匯出檔名與資源快取識別為V8.2.2-R16。研究／報告schema為UNIFIED_RESEARCH_R16。
- 保留五段式新手摘要；完整研究補上來源口徑、情境、確認與失效、型態及外部資金限制。
- 個股查詢與六套濾網的研究卡片新增「查看結構證據圖」。摘要不強制多加一頁。
- 證據圖繪製80根完成日K、MA5／20／60、成交量、前5根均量、突破線、候選防守、最近上方關卡；有合格情境才畫失效線。符合定義的W底／三角最多畫兩個，形成中用虛線。沒有符合的形態就不硬畫。
- 圖片由共享分析結果繪製，不另算訊號。這不是艾略特1–5／ABC數浪圖，也不是主力交易資料圖。

未執行全市場逐股掃描、樣本外績效回測或實際交易；沒有勝率改善結論。新模組無額外網路請求，沿用共享日K。

## 使用與回復

部署後重新整理，版本標示應為V8.2.2-R16；完成個股查詢後展開研究卡片，選「查看結構證據圖」。資料不足時不提供圖卡；缺外部資金仍會明列未知。

回復時還原本次前端檔案與index載入順序到部署前版本，不回退data/market已驗證行情。原始歷史研究按版本與參數另存，不覆寫舊快照。
