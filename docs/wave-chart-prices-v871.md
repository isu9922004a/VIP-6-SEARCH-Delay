# V8.7.1 波浪圖片：關鍵價位、多空白話與手機配色

原本獨立波浪圖片的繪圖呼叫沒有傳入原報告價位，因此表格有數字、圖內卻沒有標註。這與是否符合波浪規則無關。

## 新增呈現

- 個股與兩個大盤入口共用原報告價位、最新完成收盤及原有MA20，將數字直接標在圖旁。原三價位及未知值保留，不重新推算或用0補缺。
- 浪的轉折標籤加入真實價格，仍按原日期／高低價連線；候選保留「待確認」。同一側標籤依日期排列，避免順序倒置。
- 價位標籤獨立排在K線右側，連線對準真實價位。圖外價位明寫圖外，不冒充在圖內畫線。收盤與MA20只連到目前位置，平均線本身仍按逐日數值繪製。
- 圖下說明轉強、支撐與原失效參考的用途；碰到價位不是買訊，原失效參考也不是每個人的停損。
- 同時顯示「第幾浪候選」與「眼前偏多／偏空／回檔／反彈」。眼前方向使用同一批已完成日K的最近3個交易日收盤變化，加上原MA20位置與方向；不是新預測模型。
- 若舊上漲分段仍是候選、最近價格卻回落，明寫候選與回檔，避免把數浪直接當成目前正在主升。無合格浪型時不硬填第幾浪，但已核對價位仍可顯示。
- 波浪獨立手機圖片採較深的文字、較清楚的紅綠K線、均線與彩色價位框。維持白底與台股紅漲綠跌；文字配色在實際淺色背景的對比至少4.5:1。

維持1284×2778、浮水印、PNG下載、既有分享流程及查詢變更攔截。原專業圖片的固定版面保留。沒有新增行情API請求，沒有改動數浪規則、原策略條件、排名、停損、Kronos或Worker契約。
