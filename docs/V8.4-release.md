# V8.4 圖片報告與介面更新

個股專業版統一採用提供的淺色參考版型：行情階段、空手／持股建議、十格關鍵價位、ABC 與真實 K 線、三種走法、判斷依據、七項條件分、進階價位與支撐壓力共振。所有股票使用同一個共用產圖入口，內容取自目前股票的既有分析；沒有針對華通設定例外或固定價位。長線參考與目前 ABC 目標分開標示，資料不足時保留待確認提示。

所有既有浮水印入口共用 `report-watermark-v84.js`：淡灰色斜向主字、底部淡字及邊框來源字。專業版主字放在 K 線區，深色報告使用相應灰階。浮水印直接畫入圖片；預覽、PNG 下載及分段分享共用繪製流程。移除以報告標題代替浮水印的做法，並防止重複蓋印。

修正完整個股報告視窗蓋住圖片預覽及下載按鈕的層級問題。更新工作台、手機操作間距、焦點樣式、圖片預覽與日夜配色。精簡報告產圖時防止重複點擊，並在編碼完成後重新核對股票／大盤資料，避免顯示前一次查詢圖片。

## 驗證

- `node scripts/run-all-tests.cjs`：486 項通過，0 失敗。
- `node scripts/tests/kronos-v83-browser.cjs`：個股及獨立大盤的正常／浮水印圖片、模型資料、手機寬度，以及圖片分享／剪貼簿交接通過。系統分享以替身驗證圖片負載，不代表已向 LINE 傳送。
- `node scripts/tests/v84-report-browser.cjs`：7 檔錄製行情經實際查詢入口產出專業版 PNG；原資料保持不變，浮水印版有實際像素差異。實際操作新手、專業、三盤、寶塔線圖片按鈕並下載 PNG。
- 同一瀏覽器測試涵蓋主升、當沖、強勢、寶塔、餐廳、結構 A／B、大盤圖片入口、圖片剪貼簿、多頁 ZIP，以及 390／428／1440px 寬度。
- 沒有候選時驗證圖片按鈕保持停用。餐廳、結構的正向產圖案例使用明確標示為「合成測試股」的測試資料；錄製掃描只用於匯出回歸，不宣稱完成當日全市場掃描或行情認證。

測試使用已安裝的 Chrome 與 `playwright-core`。可透過 `CHROME_BIN`、`PLAYWRIGHT_MODULE` 指定環境；`V84_RENDER_ONLY=1` 僅驗證七檔專業圖片，`V84_SCAN_ONLY=1` 僅驗證策略匯出。歷史錄製資料與合成案例保存在壓縮測試檔，不會被正式網站載入。

正式網站上線後可執行 `node scripts/tests/v84-live-smoke.cjs`，使用真實網站與資料服務確認 V8.4、資源載入、華通專業圖片及獨立大盤圖片。

圖片輸出仍須先完成查詢並取得可用資料。沒有合格候選、來源缺漏或行情不一致時，維持原本的提示與限制，不補造結果。
