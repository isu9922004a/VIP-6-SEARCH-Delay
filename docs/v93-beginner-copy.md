# V9.3 新手白話版與個股生命線入口

從最新 main `d4d3486296adbf1d183861887e849f7dbdb3e4d0` 接續，保留 V9.2.1 的圖層分離、日期定位與全部核心計算。

- 「失效條件」改為「原看法重查價」；上下關卡、確認與風險用問句及短句呈現。
- MA20 說明為 20 日平均價；ATR 提醒說明近期股價起伏較大。仍保留指標縮寫供核對。
