# V9.3.2 全部個股生命線驗收

範圍是正式研究清單的全部 1,965 檔，含未入選、限制觀察及資料不足個股，不只 Top 8 或 8099。行情日 2026-11-13。

每檔執行：官方研究檔 SHA256、官方來源契約、原始 K3～K0 價格與日期、獨立收盤路徑判讀對照、首次突破／跌破、目前角色、歷史研究日重現、新手文案、1284px 真正 PNG 編碼、完整教學、文字邊界與重疊。近期圖座標另有變形測試：改變歷史生命線，不得影響近期圖價格座標。

Node 命令：

```
node scripts/audit-life-v932-universe.cjs /tmp/v932-all-stocks
CHROME_BIN=/usr/bin/google-chrome node scripts/tests/life-v932-universe-browser.cjs /tmp/v932-all-stocks
```

第一個命令自動使用與行情日相符的原始官方回應壓縮檔，來源為交易所 HTTPS 端點原文，不是合成資料。若未提供該日重新核對回應，結果會明列只核驗封存來源，不能宣稱已重新取得最新官方日報。

## 官方成交股數版本差異

全部 1,965 檔的開高低收均與重新取得的兩交易所日報一致。11 檔成交股數與原封存不同：2308、2330、2376、2408、2883、2885、2887、2890、2891、6446、6488。

原研究套件產製於 2026-11-13 15:11（台北時間）；對照日報取得於 2026-11-14 12:49 左右。可證實的是同日來源版本存在差異，不推定為特定交易種類。逐筆數值、兩份來源 SHA256、時間與原歷史指紋見 evidence/v932/all-stocks-source-audit.json。

不覆寫原行情，不改六套策略的入選、評分或排名。只在生命線研究中，對符合日期及原歷史指紋的差異資料標記量能待核對，量比設 null，移除量能確認文字，保留已核對的價格事件。PNG 首屏、風險區及成交量圖註記會直接顯示待核對。明確 asOf 的歷史重現不使用後來才取得的修訂資訊。

research-life-source-audit-v932.js 是由兩份完整官方回應自動生成的日期限定資料證據，不含任何股票生命線狀態、買賣結果或例外判斷；核心一律套用相同規則。重新生成：

```
node scripts/build-life-source-audit-v932.cjs original-twse-response.json original-tpex-response.json
```

## 可追溯輸出

core-universe.json／csv 包含每檔結果、原因、資料根數、狀態、原線及目前角色。
png-universe-0.json 包含每檔實際 PNG 的尺寸、SHA256、教學區、雙圖資料日期、裁切與重疊檢查。保留各狀態的真實代表圖片，避免保存數千張相同模板造成不必要的巨大交付。

資料不足或沒有 K0 仍列入清單，不能省略或補造訊號。PNG 測試是 Chromium 手機尺寸模擬，無 iPhone 真機。績效維持未驗證。
