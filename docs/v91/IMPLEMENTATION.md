# 石頭少爺 V9.1｜2560戰法｜25日均線突破

本版建立於已合併的 V9.0 PR #33，保留 K 線研究、歷史行情與其他五套策略。正式策略仍稱「2560」，位於第五套；前端展示版號 V9.1，獨立策略模型版號為 2560-STRATEGY-V2.0。

## 唯一三項必要資格
* #9041：昨收 <= 昨 MA25 且今收 > 今 MA25；最近完成交易日新突破，不接受盤中未收盤或先前已站上。
* #9012：已可驗證部分為近 5 日均量 > 近 60 日均量（股為單位）；原始截圖另三組均量週期未能證實，不猜測、不加條件。所有 PASS 必須明示「#9012量能規則部分還原，待確認」。
* #533：今日 MA5 > MA40（嚴格大於），不要求當天才交叉。

判定 = 三項同時成立；失敗為 FAIL、60 根完成有效交易日不足為 INSUFFICIENT_DATA，資料不一致為 DATA_ERROR。排除股票母體與現有安全、日期、資料口徑驗證保持原樣。

## 解除舊版專屬限制
不再將「今日 MA5 上穿 MA40」「MA5 與 MA25 同時上升」「MA5 下彎排除」「跌破 MA5 強制出場」當成 2560 的資格或買賣規則。V9.1 沒有指定正式出場策略；研究性固定 1／3／5 交易日結果不得解讀為交易指令。

## 風險資料，不可偷加為資格門檻
顯示 MA5 乖離、MA25 突破幅度（不等於隔日收益）、VMA5/VMA60 比與今日量、今日量相對前日及 VMA5、上影線比例、K 棒實體比例、前 20 根最高價差距、MA5/MA25 觀察價。超過 3%、6% 的乖離區間與放量>=3倍 VMA5 僅是尚未回測的警示。

## 保護、報告、快取
保留代號排序，不宣稱勝率；Top 8 不補滿；沒有正式合格股票可正常空榜。圖卡 1284px 單欄，分頁避免超過 canvas 高度，文字和 PNG 使用相同候選快照；一般及浮水印共用來源。更新 index、market-outlook、version-v50、PNG audit 與腳本 URL 快取參數；使用新策略版本拒絕舊 V9.0 快照。其他五套策略程式雜湊依 scripts/fixtures/v90-protected-baseline.json 持續核驗。

## 正式發布條件
執行 npm test、npm run test:contract、全市場資料審計與 Playwright 圖片測試。須檢查 GitHub Actions job、部署後官方站資源版本與手機 PNG。若 CI 或實際網站驗證未完成，不能宣稱已發布。無線上 LINE 實際送達驗證，不得將 native share API 呼叫等同對方已收到。
