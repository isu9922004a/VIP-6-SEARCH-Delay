# 個股圖片按鈕移至文字分析前方

原按鈕群組位於完整個股報告底部，主畫面又預設收合完整報告，使用者必須打開明細並捲到底部才可匯出。

現在查詢完成後，主畫面的順序是：搜尋區、圖片報告與複製按鈕、文字摘要。頁面會捲至按鈕區；打開完整技術明細或四策略報告時，同一個按鈕群組也放在文字前面。關閉明細後回到主畫面原位。

移動的是原本DOM節點，沒有複製按鈕。新手、專業、浮水印、波浪、補充研究圖片、文字複製及相關選項均保留原ID與事件處理。原先就在搜尋區的精簡圖片按鈕保留原位。

正在查詢時隱藏舊按鈕群組，完成後顯示目前股票與日期。長版技術說明保留於收合的「價位與資料使用說明」。股票資料同時接受stock與code欄位，不修改原始報告。

這是介面順序調整，不改分析、排名、模型、停損或圖片計算。大盤入口保留原排列；切換大盤或策略分頁時不顯示個股按鈕。

本地驗證：25項波浪／圖片瀏覽器檢查、29項一般介面檢查、2項部署檢查測試通過。追加主畫面／完整報告／四策略報告的先後位置、原節點及事件保留、不重複ID、查詢期間隱藏、完成後捲至按鈕、390／428／768／1440寬度與直接PNG下載檢查。未操作實體iPhone或LINE收件。

版本維持V8.7.1，快取ACTIONSFIRST1。部署檔案核對加入工作台JS與CSS，總計55檔。僅Pages前端發布，不需要Worker部署。回滾可反向提交本次介面修改，保留行情資料，經原發布流程重新上線。
