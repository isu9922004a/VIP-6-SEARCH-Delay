# 石頭少爺 V8.6：推論、風險與驗證

V8.6 保留 V8.5 的固定權重與原始模型輸出，新增可追溯執行收據、獨立技術風險路徑及可重複回測。**沒有重新訓練模型，沒有足夠證據宣稱準確率提升。**

## 已稽核的真實推論

- 上游 `shiyu-coder/Kronos`，MIT，程式提交 `67b630e67f6a18c9e9be918d9b4337c960db1e9a`，原始檔位於 `third_party/kronos/model/`。
- `NeoQuasar/Kronos-small` 權重修訂 `901c26c1332695a2a8f243eb2f37243a37bea320`；tokenizer `NeoQuasar/Kronos-Tokenizer-base` 修訂 `0e0117387f39004a9016484a186a908917e22426`。`kronos/model-lock.json` 固定版本；缺少鎖定檔直接失敗，不自動改載最新版。
- `kronos/run.py` 真正載入 PyTorch 模型、tokenizer，呼叫 `.eval()` 和 `torch.inference_mode()`。既有 GitHub Actions 安裝 CPU torch 2.7.1。沒有模型 HTTP 服務偽裝、技術分析替代或隨機價格生成器。
- 最多160、最少63根完成日K，核對資料截止日、OHLCV、成交股數單位與交易日曆。指數價格為官方指數點位；個股為未還原成交價，公司行動尚未充分核驗。
- 模型六個數值通道為 open/high/low/close/volume/amount，另有日曆時間特徵。每個輸入視窗各通道以 mean 與母體 std 正規化，分母 `std+1e-5`，裁切 ±5；解碼後乘回 `std+1e-5` 並加 mean。因此輸出為價格／量值，非直接預測報酬率。
- 缺少 amount 時，上游 batch 路徑以 `成交股數 × OHLC均價` 代理；這不是官方成交金額。V8.6 明列限制，維持相同輸入語意，沒有以變更資料冒充精度提升。
- 32個 batch rows 各自進行隨機 token 抽樣，`pred_len=1`, `T=1`, `top_p=.9`, `sample_count=1`；最後一項防止上游先平均多條路徑。seed 83001 是可重現設定，不是模擬價格；相同 token 結果可能重複，32條不等於32個交易日。
- 原始 close 相對當日close大於 +0.3% 計偏多、小於 −0.3% 計偏空，其餘持平。偏多／空取樣各達65%才標示該模型方向，否則分歧；門檻集中於 `research-v86/market-config.js`。V8.5 基準分類器封存於 `scripts/backtest/v85-forecast.cjs`。
- 預測對象是日曆核驗的下一交易日，單日原始OHLC。保留所有有限正值open/close；不合理high/low不修造，列出異常筆數，只顯示收盤分布。

## 執行與降級

新推論附 `execution`：權重、tokenizer、runtime、上游程式、輸入 tensor 與原始取樣 SHA256，行情截止時間、目標日、seed、32筆數、PyTorch/Python版本、裝置、GitHub run/commit、開始結束時間。瀏覽器同步核對來源／日期／筆數與IEEE754原始輸出指紋；完整SHA供離線重算。這是可追溯收據，**不是數位簽章或獨立遠端運算證明**。

舊輸出無新收據時標「歷史輸出／執行收據未核驗」；不宣稱已實跑。收據損壞、來源不符、過期或模型失敗時模型不可用，僅保留明示技術分析，不補造AI取樣。發布端拒收缺少有效收據的新結果。定時更新與資料一致性檢查沿用；日誌保留不可用原因，指數原始推論與可對齊的輸入日K另存不可覆寫日期／內容指紋檔。

## 獨立風險與綜合層

`research-v86/market-regime.js` 分別產生 MA5/20/60位置與斜率、RSI5/10/14、MACD、前日／前20日高低、成交量比、ATR、波動率、缺口、連跌結構。十類狀態皆可辨識；優先標風險但保留所有旗標。區別盤中收復／收盤失守、未確認／延續確認突破、超跌反彈／符合多重結構的反轉。

急跌分級用可檢視布林規則，沒有人工加權宣稱準確率。RSI超跌不是買點。模型原始方向獨立保留；模型方向與技術相反、模型分歧或模型偏多但高風險時綜合層保留方向，不修改原始路徑。模型10–90%收盤帶及與1.5ATR的聯集為**未校準參考**，不是有保證的預測高低點。


凍結 `data/backtest/v86/source-frozen.json` 的11/02以前行情；逐日只傳前綴給共用真實推論函式，正規化亦只用此前綴。11/03另存 outcome-only，不能傳進11/02特徵。固定規則與程式摘要先封存，沒有門檻最佳化；依時間50%訓練、20%驗證、30%測試，測試不參與調整。一日一列，不以32取樣膨脹樣本。

A為封存V8.5分類＋相同真實模型，B純技術，C保留原始模型中位數並由風險層管理分歧。B無學習型點估計，MAE明列零漂移基準；C與A中位數相同，MAE理應相同。報告列方向accuracy（棄權也算未命中）、balanced accuracy、方向覆蓋率／有判斷時命中、漲跌命中、報酬MAE、區間涵蓋與寬度、未校準取樣比例Brier/ECE、各市場狀態、急跌−1/−2/−3/−5%敏感度、事件數及分母為零的null。不能把增加區間寬度視為精度提升。

限制：僅120根已留存指數資料；可評分日期與獨立測試期短，急跌事件少。這是現在產生的事後逐日推論，非當年已發布的預測紀錄；預訓練資料重疊未知。歷史日K來源與實際交易日曆可核對，但尚無每一天當時保存的完整資料修訂與休市公告時間快照，無法證明所有日曆資訊當時皆已公布。因此不能視為完全點時資訊驗證或已證明可獲利。11/02案例使用封存的當期資料，11/03僅評分。後續應累積至少60個未參與調整的測試交易日及足量急跌事件，並另做即時前瞻驗證。
