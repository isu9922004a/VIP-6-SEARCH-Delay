## 修改與操作

- 首頁只保留標題、盤後掃描與主要狀態。完成交易日直接顯示「2026-11-13 盤後結果」，不把週五行情寫成週日的今天。
- 正式候選、A/B/C、資料不足放在主要區域；原15項統計、母體、來源、快照及全部名單均保留在展開區。
- 排名直接使用 V9.7 `snapshot.top8`；產圖前另以原 `summarize()` 核對原序與資格，沒有新增排序公式。同分仍依原分數、距離、股票代號順序。
- 每張卡片先顯示排名、股名代號、收盤、K3價、距離與風險；分數、方向與一句結論分層呈現。保留「查看圖片報告」與「完整個股研究」兩個入口。
- 「產生前八強圖片報告」直接讀完成掃描的快照，不重新掃描、不抓新價。只有3檔就只畫TOP1～3，0檔則顯示沒有符合條件的股票；未完成或停止不得產生正式排名報告。
- 資料不足或服務失敗時，網頁與每張排名圖都顯示「排名僅代表已成功核驗的範圍，非完整全市場排名」。
- 新增的呈現模型同時供網頁與排名圖使用，綁定代號、日期、事件、價格、K3來源、分數及快照。任何不一致直接拒絕產圖。
- 個股直接開圖沿用V9.4檢視器、單頁PNG／JPG分享與ZIP。第一頁移除重複結論，量能細節移到技術頁，並以同一份真實近期K線填補原有留白；原證據完整保留。
- 重新掃描、切換快照、股票或策略會使舊預覽與分享失效。Canvas失敗會顯示具體原因，不提供空白圖或舊下載。

介面參考 [QuantGems](https://www.quantgems.com/) 的資訊層級、重要數字與排名概念，未複製其程式、商標、圖片或完整介面。深藍、金黃、薄荷與風險粉紅沿用本專案規格。第④套採獨立深色面板，其他策略及主頁主題保持原樣。既有 `.research-inline` 隔離機制避免舊版全域翻譯器把「TOP 8」錯改成「第8名」，未更改全域文字轉換或分析函式。

## 發布與回復

執行 `npm ci`、`npm test`、`npm run test:contract`、`npm run research:validate`，再跑舊個股、大盤及新排名瀏覽器驗收。PR必要CI通過且同步最新main後才合併。使用既有Pages流程，正式站重新核對版本、資產位元組、真實掃描、排名與圖片後才宣告上線。

不需要Worker部署。回復時從最新main建立revert PR，只撤回本版呈現變更；禁止reset／force-push或回退正式行情。生命線、K0與分數原本就維持V9.7。

研究分數不是上漲機率，生命線不是主力真實持股成本。歷史時點資格與成交資料仍不足，績效未驗證；本版不宣稱提高勝率。
