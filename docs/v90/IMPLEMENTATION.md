## 2560怎麼看

「今天MA5剛穿到MA40上方，而且MA5、MA25都向上，才列新交叉。」昨天已在上方就只列觀察；MA5持平不算上升。三個SMA都用同一份完成日K原始收盤，不使用均量交叉、JMA或假設盤中收盤。至少41根有效日K才能比較昨天的MA40。來源沿用已核對的未還原官方OHLC；不混用還原價或跨未核對缺口。除權息口徑矛盾、零量或缺漏，列資料不足。

出場提醒另算：「收盤低於MA5，已有持股者核對原出場計畫。」等於不算跌破，不假設使用者持股，也不宣稱已成交。

股票母體沿用第五套普通股界線，另依既有官方產業對照排除金融股及ETF。`scan-exclusions-rsi-v5328.js`明寫為三套scanner共用，舊第五套未套用其中的生技／營建／150張／1500萬門檻，因此本次沒有把它們偷偷加入2560。TDR依既有母體排除。產業缺漏不猜測，列資料不足。排序未新增分數，採代號固定排列並標「非強弱排名」。Top8只列實際通過數。

## 九種K棒研究線索

以下是可重現的工程研究定義，尚未經使用者逐一確認或樣本外驗證，全部標示研究候選，不是正式買賣訊號。方向背景僅看型態之前5根完成日K的收盤變化，不使用未來浪底。比例以原始OHLC計算，零振幅比值為null，前根零實體回吐／收復比值為null。

| 型態 | 數值定義與位置 |
|---|---|
| 錘子 | 下跌背景；實體>0且≤振幅35%；下影≥2倍實體、上影≤振幅10% |
| 倒錘子 | 下跌背景；小實體，上影≥2倍實體、下影≤振幅10% |
| 流星 | 同倒錘子幾何，但位於上漲背景 |
| 十字 | 振幅>0，實體≤振幅10%；不直接給方向 |
| 多頭吞噬 | 前根下跌、今根上漲；今實體包覆前實體，至少一邊嚴格超過 |
| 空頭吞噬 | 與多頭吞噬鏡像 |
| 烏雲罩頂 | 上漲背景，前陽今陰；嚴格版開盤>前高，收在前實體中點下且仍>前開；簡化版只要求今開≥前收，另列研究候選 |
| 曙光初現 | 下跌背景，前陰今陽；嚴格版開盤<前低，收在前實體中點上且仍<前開；簡化版今開≤前收，另列研究候選 |
| 晨星 | 前段下跌；首陰實體≥振幅55%；中根實體≤首根一半且≤自身振幅35%；末根陽收復首實體中點；嚴格版另需中根實體在首收下方且末開>中根實體上緣；簡化版不作缺口要求 |

方向型態形成當天全部待確認。後續完成收盤嚴格越過型態最高／最低才確認；反向收盤越過型態另一端則失效；3個交易日未確認便到期。十字不憑自身指定方向。狀態帶signalDate、availableAt、confirmedAt、failedAt。已確認後失守仍轉失效，不把過去確認當永久成立。

昨日高低點和前20根高低範圍分開標示。盤中碰過與收盤站上分開；同日觸及兩側明說「只看日K，無法知道先漲還是先跌」。前20根範圍不是保證支撐，型態失效價不能取代原停損。

## 測試、全量驗收與回測缺口

新增策略、九種型態、同日雙向觸價、零分母、確認延遲、缺漏／錯代號／錯日期／錯口徑、完整零檔與部分零檔、快照防竄改及保護來源測試。瀏覽器驗收直接編碼PNG、檢查文字邊界、390／428／768／1440預覽、下載及原生檔案分享接口，核對一般與浮水印內容一致。自動化可驗證交給手機分享選單的PNG，無法證明外部LINE帳號已送達。

`scripts/audit-v90-universe.cjs`逐筆核驗官方歷史檔SHA256及市場指紋，沿用共用歷史取得方式，核對所有標的狀態與7檔或實際每日候選。執行結果以artifact為準，資料日期更新時重新執行，不固定寫入候選數或價格。

`strategy-2560-backtest-v1.js`獨立重放：訊號盤後才成立，最早下一交易日開盤入場；MA5出場警示最早再下一交易日開盤。1／3／5日依真實交易序列計算，成本預設為研究假設（買賣各0.1425%、賣出稅0.3%、單邊滑價0.05%），與正式選股無關。無當時母體、日曆、公司行動證明時回NOT_VALIDATED，不產生假勝率。原餐廳策略缺少歷史逐日主力／JMA／官方漲停證據，尚不能公平比較績效。

後續正式樣本外研究須先固定訓練／測試日期、留存逐日股票母體及產業、剔除未來資料，統計每日入選數、隔／3／5日淨報酬、勝率、平均盈虧、組合回撤、換手、MA5警示比例、市況分組、假突破與五套策略重疊、樣本數與信賴區間。當前有限歷史不等於已完成樣本外驗證；不宣稱提高勝率。

## 回復與風險

舊餐廳四個檔案保持原始位元組，固定基準雜湊位於 `scripts/fixtures/v90-protected-baseline.json`。緊急回復可將 `strategy-2560-config-v90.js` 的active改為RESTAURANT並同步清除快取，重新發布後舊UI會保留且新UI不取代；同時回復第五套工作區／研究標籤。完整回復則revert本次功能提交，不回滾行情、模型、Worker、歷史收據或其他五套。不同策略快照互相拒絕，不能把舊六項快照當作新2560。

資料受限的標的不列完整成功；公式／共通版面錯誤修正後才發布。未建模特殊浪型與原研究績效狀態仍保留。沒有未決事項需要阻擋本次客製化2560；九種型態門檻與交易成本保留研究狀態，未默默提升為正式條件。
