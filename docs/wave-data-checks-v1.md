# 波浪圖資料核對與舊狀態修正

公開版維持V8.7.2，PNG維持1284×2778與手機滿寬預覽。

問題有兩處：圖片只呈現第一個資料缺項，把其餘縮成「另N項待核對」；產圖前只有波浪本身DATA才重試，波浪可畫但買進資料DATA時不重試。另有顯示層沿用同股票、同日、同收盤與同K線的舊研究結果，未反映後來完成的來源核驗。

波浪報告現在優先使用現有forReport，依目前共用行情收據、來源證據及既有參數取得同一次正式研究結果，並使用該結果的既有波浪；不建立新選股或買進公式。缺資料時產圖前沿用prepareStockQuery核對、原逾時及查詢切換保護。核對不成功就保留原限制；不把可畫K線當作可買進。

資料限制圖片以2欄×3列顯示：完成日K、歷史價格、交易日期、成交量、報價規則、行情來源，各有狀態與簡短原因。未知不等於通過；不同來源數字不一致明列衝突；大盤不套個股報價規則。完整原因保留在結構化資料，不再只保留第一項。波浪的價格、量能、力道及轉折／長度待確認也完整顯示，不以「等」隱去。

買進資格仍取原openingPlan；核對完成後也可能因風險空間而NO_TRADE。維持既有原價位、K線、浮水印、下載、分享、行內事件與其他圖片輸出。保留真實短歷史、量能範圍、價格基準與商品規則限制。
