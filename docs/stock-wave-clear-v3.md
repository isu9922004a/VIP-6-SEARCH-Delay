# 全個股波浪圖片：白話與價位用途第三版

共用模板套用全部上市／上櫃個股，不在正式程式寫入特定代號或示範價格。尺寸仍為1284×2778，乾淨／浮水印／下載與LINE分享沿用原流程；顯示版本維持V8.7.1，快取識別更新。

## 這次改什麼

- 觀察價分為收盤在下方／剛好等於／已在上方；不再要求已到價的股票「等漲回」。
- 近期方向與買進資格分開描述。WAIT與NO_TRADE列出原計畫真正原因，不一律說資料不足。
- DATA按原原因碼說明歷史、日期、價格、成交量、報價跳動規則或服務限制；不把缺單項證據說成全部行情錯誤。原始原因與全部問題留在結構化資料與既有文字報告。
- 無浪號時改成「為什麼沒有浪號」，區分規則不符、高低點排列不清及資料限制；實線只表示高低點確認，數浪本身仍可改變。
- 圖上區分原突破／原回檔／原失效與新買觀察。原回檔與新買觀察不同價時，內文指出兩者用途不同。
- 完全相等價格才合併標籤；同一個標籤保留每項role、原label、數值與來源。接近或只因四捨五入看似相等的價格不合併。
- 股票波浪圖最多六個價位標籤，加入真正的新買觀察，避免圖與文各講不同來源；DATA不列尚未通過資料核對的新買觀察。
- 原三個價位全部未提供時，用一句話說明三類價位均缺，不重複列三次「還沒確認」。有值時保留原數字。
- 未啟用買進計畫時，主圖不列新買停損試算；試算數字仍保留在原計畫／結構化資料。已持有者以個人原停損優先，圖上低點或原失效價不是自動賣出指令。

## 不改動的核心

openingPlan的state、watch、stop、target、entryRange、dataIssues與買進資格全部沿用原引擎；不調整ABC/N字、波浪數法、高低點日期、OHLCV、Kronos、排名、門檻或Worker。新的條件分支僅決定顯示文字及合併價位標籤，不新增可買股票。

大盤、個股專業版與精簡版不套用這個新標籤分支。跨版本同輸入的這些圖片以PNG雜湊比較，確保未意外改變外觀。

## 驗證與示範

- 單元測試覆蓋三種價位關係、近似價不合併、缺項原因、錯股／錯日計畫、DATA不列買價、持股停損不被試算取代、原參考值不變。
- 全市場逐檔實際生成波浪與精簡PNG，檢查身分、日期、OHLCV、買進資格、標籤完整性、文字與圖片尺寸。
- `stock-wave-clear-browser.cjs` 對使用者提供的十檔股票建立同日同來源改前／改後圖片，並檢查原計畫、波浪座標與原參考值不變。
- 神基／是方／大甲的部分原方法參考價，以使用者2026/11/06截圖作**測試限定的顯示輸入**，僅在官方資料的日期及收盤一致時使用。這些值不寫入正式程式、不餵給原引擎，也不當作新計算結果；證據JSON標明USER_PROVIDED_REPORT_IMAGE。
- 原UI-only的逐位元組圖片不變工作流限UI分支執行；本次報告圖片本來就是預期變更，改用專用跨版本比較與原有全市場／功能回歸，不以舊圖片相同要求掩蓋新模板。
- 實際執行結果見PR及Actions。不使用回測勝率或預測效果改善宣稱；原研究限制保持。

## 檔案

- `elliott-wave-stock-beginner-v1.js`：共用白話模型、缺項原因、價位關係、原價位與持股說明。
- `elliott-wave-visual-v1.js`：只針對beginner股票圖啟用六價位／同價標籤排版與可讀性audit；其他分支保留原渲染。
- `elliott-wave-report-v1.js`：圖片模型版本識別更新，避免舊圖片分享身分混用。
- `index.html`、`market-outlook.html`、`version-v50.js`：僅更新本次模組快取參數，載入順序及公開版本不變。
- `scripts/tests/stock-wave-beginner.test.cjs`、`scripts/tests/elliott-browser.cjs`、`scripts/tests/stock-wave-clear-browser.cjs`：單元、功能、改前改後及其餘圖種不變比較。
- `scripts/audit-all-stock-images.cjs`：全市場加驗合併前後來源與未啟用試算不外露，增加十檔預覽。
- `.github/workflows/stock-wave-clear.yml`：新報告專用驗收／圖片證據；`.github/workflows/ui-polish.yml`：UI-only契約明確限純UI分支。
