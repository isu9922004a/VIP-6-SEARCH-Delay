# V9.2.1 研究呈現修復

基準 main：`7d8fffa1cc45b4822e073a866ebd3d439aee804b`。

本次保留選股、行情、研究、Kronos 與生命線核心運算。修改範圍為呈現、匯出、版本、測試及發布驗證。

## 實際根因

`research-integration-v1.js` 的結構圖預覽會經 `research-report-v1.js:candlePage` 進入 `research-chart-v1.js`。原圖表額外呼叫生命線 evaluate，將固定生命線與 K0～K3 畫在同一個 A/B/C 圖層。

原程式已按事件日期找 K 棒，並非任意套用最近交易日；但四個事件是相鄰交易日，集中在可見圖右側。它們的 y 座標固定為 `y0+22+i*41`，沒有連接 K 棒、碰撞排版或範圍外說明，因此看起來像右上角圖例，難以辨認對應 K 棒。生命線價位若不在圖內，整組標籤還會一併消失。

原獨立生命線圖只有文字卡片。新版將日期定位搬到獨立圖，保留 exact-date lookup，新增可測量的外部標籤區、連接線、端點與缺失狀態。

另外，原結構圖的文字採固定 y 座標，長中文可超出頁尾；新版以實際 Canvas 字型量測內容後增加圖片高度。舊 N 字投射價仍保留在有明確限制的研究文字中，移除其未命名水平線。

## 資料與保護

亞電歷史快照：`data/research/2026-11-13/4939.json`，160 根已核驗官方日K。正式研究原本只把最近 20 根傳給生命線模組；本次維持同一研究輸入，沒有為了畫圖擴充偵測範圍。結構圖顯示最近 80 根。

2026-11-13 收盤 61.90 元；生命線 50.20 元；K3／K2／K1／K0 為 2026-11-06／09／10／11；原狀態 NEUTRAL（盤整／待確認）、事件狀態 BULL_SUPPORT_WATCH。收盤低於 MA20 與 ATR 波動風險持續顯示。

結構圖正式價位為突破觀察 85.00 元、最近壓力 65.50 元、下跌觀察 50.20 元，失效條件尚未確認。相同數值不代表研究來源相同：結構圖從結構資料取值，生命線圖從生命線事件取值。

`scripts/fixtures/v921-protected-baseline.json` 保存 26 個核心來源雜湊、首頁內嵌策略程式雜湊，以及真實 4939 輸入、完整研究輸出、生命線輸出的雜湊。所有值由修改前基準產生。

本機重新跑 1,965 檔 2560 universe，完整逐檔輸出與修改前一致：15 PASS、1,656 FAIL、250 資料不足、44 排除。其他五套的核心及首頁內嵌計算受來源雜湊保護，既有六套 sidecar 瀏覽器測試另驗證候選、分數、資格、順序未被呈現層改寫。

## 驗證方式

- `node scripts/run-all-tests.cjs`：完整原有單元測試與新增精確定位／來源保護測試。
- `node scripts/tests/research-v921-browser.cjs <輸出目錄>`：真實 Canvas PNG、實際文字 glyph 邊界、主要文字相交、標籤座標、同日期對應、無事件、部分缺失、範圍外、長內容、多方／空方、模型隔離、手機卡片、圖片預覽、PNG 下載。
- 分享測試攔截瀏覽器原生 share API，檢查完整檔案送入介面；不向 LINE 或其他接收者實際傳送。
- 既有 `research-browser.cjs` 與 `research-context-r16-browser.cjs` 針對六套策略控制、原始候選／分數／順序、欄位保留、手機邊界與圖片進行回歸。
- 新增 CI 上傳實際 PNG 與完整幾何證據。既有 frontend workflow 在 verify 與 live 兩階段都執行新版圖片驗證，deploy 仍由 verify 成功後才啟動。

手機驗證使用 Chromium 428×926、3 倍像素與觸控模擬；不能代稱實體 iPhone Safari／LINE 已測。歷史快照在驗證報告中明確標示日期，未改寫正式市場資料。

本機完整測試遇到 Windows 的 python3、bash 與 `/tmp` 依賴；此環境限制須由 Linux CI 結果補足，不將其列為通過。完整發布狀態以 PR 檢查、verify → deploy → live 與正式網站實際輸出為準。
