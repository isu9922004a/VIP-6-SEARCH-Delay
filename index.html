        綜合目前的位置、量價、趨勢、上方空間與風險；這是背景條件分，不等同「現在可以追價」。近端是否適合追，另外看最近戰術壓力／支撐與近端進場檢查。

        表示目前價格到程式選定的上方關卡，距離約5%。只是在量距離，不是預告還會漲5%。
        MA20／20日均線
        最近20個交易日收盤價的平均。日20MA看20個交易日；月20MA看20個月，兩者不同。
        乖離＋8%
        表示股價比指定均線高約8%；負數表示在均線下方。正數越大代表離均線越遠，不等於越適合追買。
        RSI5＝80
        以5期計算的近期上漲／下跌力道指標，範圍0～100。80表示近期上漲力道偏強，還要看是否過熱、力道轉弱及價格支撐；不是80%上漲機率，也不表示一定立刻下跌。
        量比2.0倍
        表示成交量是「指定比較基準」的2倍。要看標籤寫的是近3日、5日或20日均量，不能把不同基準混在一起。放量也可能發生在下跌或漲不動的時候。
        空間比／第一關卡空間比
        「中短波段空間比」與圖片的「最近關卡空間比」使用不同價位地圖；最近關卡空間比只量到最近上方關卡，不是整筆交易的完整盈虧比，兩者都不是勝率。
        突破品質8／10
        表示程式檢查的突破證據得到8分，滿分10分；是條件評分，不是80%成功率。仍需看價格是否守住突破位置。
        Fib 0.618／1.618
        是計算回檔參考價或延伸目標的倍率；旁邊標示的「元／點」才是價格。倍率本身不是成功率。

        ⑤ 📐 費波那契 N字分析
        N字與月線是兩套不同判斷。新手先記：A＝起漲點、B＝前波高點、C＝回檔低點；A起漲 → B前高 → C回檔 → 再收盤突破B，才是完整費波那契N字確認。
        ABC 新手白話：A＝這一組N字的起漲點；B＝A上漲後形成的前波高點；C＝B回檔後形成的有效低點。只有 C 已形成後，再由 C 回升並以完整日K收盤突破 B，才正式啟用 0.618／0.764／1.618。若 C 還沒形成，就算最新收盤先漲過 B，也不能倒推成完整 Fib N字。
