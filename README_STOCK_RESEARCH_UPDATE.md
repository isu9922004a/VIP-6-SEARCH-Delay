# 石頭少爺 V8.2.1｜四策略研究「個股查詢摘要」圖片同版修正

## 修正目的
使用者從「⑦ 個股查詢｜專屬研究」產生圖片時，使用**與四策略研究濾網摘要完全相同的欄位來源、排列與視覺版型**，而不是把個股報價、RSI5、日MA20、資料來源另外插入圖片。

## 實際修改
1. `research-report-v1.js`
   - 個股與濾網圖片統一用同一份 `lines(a)` 資料，套用相同的分頁與卡片渲染。
   - 圖片中個股模式標題正式改為「**四策略研究｜個股查詢摘要**」。
   - 移除單股圖片額外插入的「個股收盤、日RSI5、日MA20、報價來源」四欄；這些數值仍保留於原個股查詢資訊，不變更原始報告資料。
   - 保留九個可辨識構成部分：股票與代號、現況、研究重點、關鍵價位、風險、研究A/B、到價提醒、資料狀態、摘要結論。
   - 保留圖檔的資料稽核資訊與單股類型標記；缺值一律顯示缺值，不自行推估。
2. `research-integration-v1.js`
   - 圖片預覽視窗標題與個股圖片按鈕同步更名。
3. `index.html`
   - 對研究圖片與整合模組的 script 網址使用新的 `V8.2.1-STOCKSUMMARY2` 快取鍵，避免手機讀取舊 JS。
   - 其他原版前端 V8.2.1 顯示代號保持不變。

## 不改變的部分
- 六套原濾網選股規則、分數、資格、排名與原榜。
- 個股查詢的收盤、RSI5、MA20等原有顯示或文字匯出資料。
- 不把研究摘要視為買點或命中率。
