新版代號：**R5.3.2.8.1-TOWER-SHADOW.4**。

解壓後將本包檔案按原資料夾結構放入既有網站儲存庫，`index.html` 應位於網站根目錄。保留 `data/`、`scripts/` 及隱藏的 `.github/` 資料夾；後者是既有行情與排除名單自動更新流程。

本包只提供目前網站部署所需的程式、行情資料與更新流程，不附舊版ZIP、還原工具、歷史報告或測試圖片。保留的歷史行情是現行更新程式使用的資料，不是舊版網站。

本次在第四濾網排名0檔時，於複製戰報另列分析成功個股的名稱、代號、收盤、趨勢、寶塔方向及未入選原因。成功明細不作候選排名；缺資料與失敗不列成功。舊摘要沒有股票明細時，不猜名稱，請重新掃描後複製。前端及匯出版本已同步更新。原三策略、第四濾網的判讀、計分、資格與排名保持，個股原專業圖與獨立寶塔圖均維持1284 × 2778。

書籍內容目前部分實作：尚未完整串接布林、KDJ／MACD／CCI、雙頂雙底頸線、突破後回測及獨立結構停損。這個代號代表既有獨立報告與排名戰報更新，不代表上述全書策略已完成。

往後更新前端請提升 `version-v50.js` 的發行代號並同步 `index.html` 資源參數，再執行 `node scripts/verify-release.cjs`。已有Git版本歷史時可加 `--base HEAD`（未提交修改）或 `--base HEAD^`（剛提交修改），檢查有前端修改卻忘了升版的情況。

這是供您自行上傳的部署包，本次未代為推送或部署；實體iPhone／Safari、正式行情與績效未於本次實測。
